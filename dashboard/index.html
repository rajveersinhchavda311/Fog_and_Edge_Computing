Algorithm inspection — how the detection works
Component 1 — Temporal pattern matching (DTW)
Each zone's recent density curve is min-max normalized and compared against a reference pre-stampede S-curve using Dynamic Time Warping. Lower distance = closer match. Confidence = 1 − (distance / max distance). A zone is surging only if it passes both the confidence and the absolute-density test — DTW is scale-invariant, so shape alone is not enough.

Component 2 — Cross-correlation wave detection
Every adjacent pair is correlated across time lags. A wave is confirmed only when the source zone is surging and correlation exceeds threshold and lag is positive (B follows A) and both flow vectors point the same way. Rejected rows show which condition vetoed the wave — this is what separates a real propagating wave from two coincidental spikes.
